Start locally, choose deliberately

The offline demo plays fixed fictional responses and makes no model calls. Select a provider on a receipt and explicitly run it to request a proposal.

For an installed local Ollama model, restart the server with:

python3 -m accounting_harness serve --enable-providers --ollama-model MODEL_NAME

For OpenAI, configure OPENAI_API_KEY in your local environment, then restart with --enable-providers. Keys stay out of this browser. API calls may be billable.

Live model accuracy, compatibility, latency, and billing remain unverified until the separate live evaluation. An available provider only means startup configuration allows requests.
